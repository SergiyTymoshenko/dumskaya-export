# Перевод сайта DUMSKAYA DESIGN (с русского на украинский / английский)

Студия дизайна интерьера DUMSKAYA DESIGN (основатель — Ирина Думская). Работает в Братиславе (Словакия)
и Вене (Австрия): дизайн интерьеров, мебель на заказ, ремонт под ключ, архитектура, 3D-визуализация.
Сайт — портфолио проектов, услуги, цены, статьи-советы, каталог кухонь.

## Задача
Перевести каждую строку `src` из входного пакета. Это готовый текст сайта, а не черновик:
- Пиши как носитель языка, копирайтер студии премиум-класса: точно по смыслу, естественно, без кальки.
- Не добавляй и не убирай факты, цифры, обещания. Не сокращай. Не добавляй городов, которых нет в исходнике.
- Там, где в исходнике упоминаются Братислава, Вена, Словакия, Австрия, используй формулировки, которые
  люди реально вводят в поиск на этом языке (см. «SEO» ниже) — это главная SEO-задача перевода.
- `kind: "alt"` — описание фото для поисковиков: коротко, по делу, без кавычек.
- Заголовки (короткие строки без точки) — в обычном регистре (сайт сам делает их заглавными).

## Формат (строго)
- HTML-теги сохранить ровно те же и столько же: `<strong>…</strong>`, `<a href="…">…</a>`.
  Значение `href` НЕ менять вообще (ссылки на другие языки подставятся потом автоматически).
  Внутри тегов — переведённый текст; порядок тегов может измениться, если этого требует грамматика.
- Все числа сохранить (площади, цены, сроки, толщины, модели K-02 и т. п.).
- Названия брендов и материалов-брендов не переводить: DUMSKAYA DESIGN, Metropolis, Eurovea City,
  Hettich, Blum, Hafele, FREE FOLD, AvanTech YOU, Egger, Kronospan, IKEA и т. п.
- Единицы: м² → укр. «м²», англ. «m²»; «пог. м» → укр. «пог. м», англ. «linear m».
- Не оставляй русских слов. Не используй markdown.

## Как сдавать
Результат — JSON-объект {"t00001": "перевод", ...} со ВСЕМИ id из пакета, в файле
`i18n-work/out-<lang>-<NN>.json` (если удобнее — частями: `out-<lang>-<NN>-a.json`, `-b.json` …).
Затем запусти проверку и исправь всё, что она покажет:
  python3 scripts/i18n/check_batch.py i18n-work/<lang>-<NN>.json
Готово, когда проверка пишет «OK».
